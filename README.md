UDYOGAA ACTUAL WORKING DEMO

Open index.html in Chrome.

This is a front-end prototype with simulated data and working interactions:
- Navigation between dashboard, inventory, sales, tasks, experts and AI assistant
- Record Sale changes sales/order figures and adds a transaction
- Inventory restocking changes stock levels and low-stock counts
- Tasks can be completed
- Expert requests produce a working demo workflow
- AI Assistant responds to business questions
- Bundle and product actions create simulated workflows

No backend/database is required for the demo. Data resets when the page is refreshed.

- Language selector now translates static and dynamically generated buttons, including action/modal buttons.


MULTILINGUAL UPDATE:
- Every visible text node is translated, including headings containing nested elements.
- Dynamic inventory, sales, tasks, expert cards, modal buttons, placeholders and generated UI are re-translated after language changes.
- Language changes are applied consistently to all buttons and controls.
