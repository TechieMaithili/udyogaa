UDYOGAA — PREMIUM DARK-TECH REBUILD
===================================

This package is the rebuilt working Udyogaa static demo.

Updates in this version:
- Uses the supplied Udyogaa logo asset from the request.
- Corrected logo sizing/placement so the full logo is visible in the header without cropping.
- Added a polished language selector in the header.
- Added full interface translation for English, Hindi, Marathi, Gujarati, Tamil and Telugu.
- Language selection updates navigation, headings, cards, tables, tasks, expert network, AI assistant prompts, buttons, modals and dynamic demo feedback.
- Language preference is saved in the browser using localStorage.
- Preserved the existing dashboard, inventory, sales, tasks, expert network and AI assistant functionality.
- Preserved record-sale, restock, task, expert-request, modal and demo AI interactions.
- Dashboard uses the modern vertical bar graph.
- Responsive layout retained for desktop, tablet and mobile.
- Added an editable user profile modal with localStorage persistence; the dashboard greeting and header profile update immediately after saving.

Run:
Open index.html in a browser.

Hosting:
This is a static HTML/CSS/JavaScript project and can be hosted on GitHub Pages or another static hosting service.
